Grade your site's HTTP security headers — A to F

Paste any URL. Get an A-F grade across the six security headers that matter (CSP, HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy) plus the full response header set. Faster than securityheaders.com, no queue, no signup.

Use the API directly

The grader is also a JSON API. Free, no signup for the first 100 calls per day, 1,000 with a free API key.

curl "https://api.sitetrace.it.com/api/headers?url=https://example.com" \
  -H "X-API-Key: $SITETRACE_KEY"

Returns { score, grade, checks[], all_headers }. The same endpoint powers this page — the form just renders the result.
