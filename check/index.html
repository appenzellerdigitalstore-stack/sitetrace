How the dispatcher decides what to run

When you paste an input, SiteTrace runs a 5-line classifier on it client-side. If it parses as an IPv4 or IPv6 address, you get an IP report. If it parses as a URL (begins with http or contains a slash beyond the apex), you get a URL report. Anything else with at least one dot is treated as a domain. The classifier doesn't talk to any server — it just decides which of three result panels to show.

All checks run in parallel against the sitetrace-api backend at api.sitetrace.it.com. The free tier is 100 anonymous calls per day per IP — that's enough for ~30 check sessions. If you hit the cap, sign up for a free API key at sitetrace.it.com/signup for 1,000 calls/day with no per-tool math.

Each individual tool page (/what-is-my-ip/, /email-deliverability/, /is-it-down/, /seo-checker/, /http-headers/) runs a single deep check, often with lookups in your browser via DNS-over-HTTPS for privacy — your query never touches a server we operate. Use those when you want a thorough report on one input type. Use /check/ when you want a fast combined look across multiple.
