Use the API directly

The preview endpoint is also a JSON API. Free, no signup.

curl "https://api.sitetrace.it.com/api/preview?url=https://example.com" \
  -H "X-API-Key: $SITETRACE_KEY"

Returns { title, description, image, og, twitter }. The same endpoint powers this page — the form just renders the result for 5 platforms.
