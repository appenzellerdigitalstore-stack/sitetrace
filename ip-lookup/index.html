What is an IP lookup?

An IP lookup queries a public IP-geolocation database for the registered owner and approximate physical location of an IP address. Every IP on the public internet is allocated to some organization (an ISP, a hosting provider, a business), and that allocation is public. This tool checks your own IP in under a second, and the same data feeds the network and security cards below.

Frequently asked questions

What does an IP lookup tell me?

For any public IP, the lookup returns the registered country, region, city, postal code, ISP, organization, ASN (autonomous system number), and the connection type (residential, mobile, hosting, VPN, etc.). It also checks whether the IP is on known VPN, proxy, or Tor lists.

Can I look up someone else’s IP?

Yes. Type any public IP into the tool and you’ll get the same information a service sees when that IP connects to it. The lookup itself is read-only and uses public data — it does not contact the IP, does not scan it, and does not reveal any private information about the person behind it.

How accurate is the geolocation?

City-level accuracy is typical for residential and mobile IPs. Hosting and VPN IPs usually resolve to the data center or VPN endpoint, not the actual user. Country-level accuracy is close to 100% for most IP blocks.

Does an IP lookup show my home address?

No. Public IP geolocation only shows the city or region registered to your ISP, not your home address. The only parties who can map an IP to a specific physical address are your ISP and law enforcement with a court order.

Is IP lookup legal?

Yes. The data is publicly registered and the lookup is read-only. The same data is shown to every site you visit, every API you call, and every email you send.
