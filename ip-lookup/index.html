What is an IP lookup?

An IP lookup queries a public IP-geolocation database for the registered owner and approximate physical location of an IP address. Every IP on the public internet is allocated to some organization (an ISP, a hosting provider, a business), and that allocation is public. This tool checks your own IP in under a second, and the same data feeds the network and security cards below.
