Network tools & service status

Every SiteTrace tool runs in your browser and talks directly to public services — IP geo via ipwho.is and ip-api.com, DNS over HTTPS via Google and Cloudflare, HTTP status via your own fetch. No account, no app, no install, no tracking. Funded by unobtrusive ads and donations.

last updated 2026-10-02 · built by edy appenzeller · open source (MIT)

// network & ip

5 tools

What is my IP

Your public IPv4/IPv6, approximate city, ISP, ASN, and whether traffic is exposed, behind a VPN, routed through a proxy, or exiting Tor.

 →

IP lookup

Look up any IPv4 or IPv6 you have in mind — see the registered owner, approximate location, ASN, and whether it belongs to a residential block, mobile carrier, or hosting provider.

 →

IP reputation

Threat score, abuse history, and blacklist status for any IP. Useful when triaging suspicious connections or vetting a server before adding it to your allowlist.

 →

VPN checker

Confirm your VPN is actually working. The internet sees what this page sees — if the IP and geolocation look like your ISP, your tunnel is not routing traffic.

 →

Subnet calculator

CIDR to subnet mask, network address, broadcast, host range, and host count. Works with both IPv4 and IPv6 prefixes.

 →

// dns & connectivity

3 tools

Domain inspector

Type a website, get resolved IPs, HTTP reachability, and round-trip latency in one shot. Uses fetch() timing instead of ICMP since most clouds block ICMP anyway.

 →

DNS lookup

Resolve any domain to A, AAAA, MX, TXT, NS, CNAME, and SOA records via DNS-over-HTTPS. See which resolver answered and how long the round trip took.

 →

DNS propagation

Check how a domain's records resolve across 8 global resolvers (Google, Cloudflare, Quad9, OpenDNS, AdGuard, Comodo, Level3, and authoritative). Useful after a DNS change.

 →

// web status & headers

3 tools

Is it down

Paste a URL — see if it is reachable from your network, plus live status for 50+ popular services straight from their official Statuspage feeds.

 →

Bulk URL status

Check many URLs at once — 5 free per call, 100 on the paid API tier. Same logic as the Is It Down page, designed for scripts and monitoring jobs.

 →

HTTP headers

Inspect any site's HTTP response headers — Content-Type, cache directives, CORS, Content-Security-Policy, HSTS, server, cookies, plus a plain explanation of each.

 →
